# Z9 mark2 自定义快门声补丁

针对 **Z9 5.32** 的实验性源码项目，当前候选为 **mark2 v13**。仓库仅提供自行编写的补丁源码、离线工具和合成测试，不包含尼康固件、原厂资源、私有格式材料、实机数据、个人音频或可安装BIN。

## v13 改动

| 项目 | v12 | v13 |
|---|---|---|
| C15前段 | 50ms | 仍为50ms |
| C15声音循环周期 | 约50ms | 保留原周期预算并补偿短片段，长片段实测约66.99ms |
| C30/C60/C120前段 | 50ms | 40ms，长片段实测约40.01ms循环 |
| 停止后尾段 | 从50ms处开始 | C15不变；其他Cxx从40ms开始，剩余部分一次播放 |

这些数字是声音循环节奏，不是照片帧率。音频短于对应分界时循环整段且没有额外尾音；其他Cxx短于40ms的音频也不会自动获得40ms周期。普通S/CL/CH仍在每次实际照片请求时从完整选中PCM开头重触发，最后一声可以播完，未新增固定40/50ms切点或播放队列。

v13仅改变Cxx初始化逻辑。菜单、导入缓存、配置保存、回调退休和QEMU均未改；四次导入额度修复、20种内容缓存和回调安全复用已属于v12。正文和完整包均增长48B，27处集成地址不变，15处目标仅随编译布局统一移动48B。详见[版本记录](CHANGELOG.md)。

## 文件和资源边界

仅扫描卡根目录`CUSTOM_SOUND`的本层文件，目录不存在时创建；最多显示20项，仅显示文件名。支持不超过111字符的可打印ASCII文件名，不支持中文文件名。

音频须为RIFF PCM、48kHz、双声道、16位小端，长度大于0且≤1.5s；无效文件不会替换上一份声音。菜单显示`CUS`，保留原Type A–E和音量控制。配置是两个固定160B记录，包含CRC、序号和写后回读，不持续增长。

每次选择仍从卡读取验证；重复PCM复用缓存、失败可重试。每次开机最多保留20种不同PCM和一个暂存区，已发布PCM不覆盖或释放。64个回调登记仅在原生最终通知返回且请求/两路输出pending清零后复用，这不是释放PCM的DMA屏障。双卡先提交有效新配置，再停用上一张已挂载卡的旧配置。

## 验证边界

五份主要Cxx音频样本支持50/40ms循环、原生停止及一次尾音合同；C15完整拍后菜单/取景恢复仍有失败。一次固定1/200启动完成20张完整流程：原声前后对照、自定义S五次独立按压、CL1三张、CL5五张、CH10五张，18次自定义请求均有当前PCM消费证据。三档间隔中位数995.653/203.004/103.983ms，均在±25%内。慢档CL1/CL5/CH10为此前已完成阶段证据。

旧混合快慢切换方案仍失败，不能证明其与mark2因果独立。五个同模型/启动输入的普通新冷启动包含四失败一成功，不是五次完整业务通过。原生超过64次请求、所有CL/CH速度、精确1/50边界、短Cxx及尾音中快速再按、完整双卡拔插/断电和长期实机稳定性仍未获得资格。组件压力次数不替代实机次数，当前没有v13实机验收。详见[验证说明](docs/validation.md)。

## 构建

依赖与命令见[English README](README.md)。自行提供SHA256匹配的原版MAIN模块；完整封包另需原版容器和私有格式材料，工具不下载这些输入。所有输出须在仓库外私有目录。编译与整包输出必须匹配冻结v13哈希并独立回读。

本项目仅覆盖mark2；QEMU修复、mark1和mark3是独立工作。历史v11/v12保留在Git历史，无相机控制、刷写或自动安装命令。
