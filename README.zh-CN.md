# Z9 mark2 自定义快门声补丁

针对 **Z9 5.32** 的实验性源码项目，当前候选为 **mark2 v12**。仓库仅提供自行编写的补丁源码、离线工具和合成测试；不包含尼康固件、原厂资源、私有格式材料、实机数据、个人音频或可安装 BIN。

## v12 更新

- 取消每次开机四次导入尝试限制。每次仍读取并验证卡内文件；重复PCM内容复用，失败可重试。最多保留20种不同PCM内容和一个暂存区；容量满时提示错误，旧缓存仍可选。已发布PCM不覆盖或释放。
- 64个回调登记仅在原生最终回调返回、请求与两路输出pending清零后复用；这不是释放PCM的DMA屏障。
- C15/C30/C60/C120 按住循环前50ms，原生停止完成后播放一次剩余尾音。合法≤50ms音频循环整段、无尾段。原有1ms补零保持；S/CL/CH保留原快慢档规则。
- 双卡先提交新有效配置，成功后停用另一张已挂载卡的旧配置。

## 文件和菜单

仅扫描卡根目录 `CUSTOM_SOUND` 的本层文件，目录不存在时创建；最多显示20项，仅显示文件名。支持不超过111字符的可打印ASCII文件名，不支持中文文件名。

音频须为 RIFF PCM、48kHz、双声道、16位小端，长度大于0且≤1.5s；无效文件不会替换上一份声音。菜单显示 `CUS`，保留原版Type A–E和音量控制。配置采用两个固定160字节记录，包含CRC、序号和写后回读，文件不会持续增长。

## 验证边界

四档Cxx实际PCM循环/尾段/停止链路已验证。C15历史JPEG拍后恢复仍失败。普通模式部分运行完成9次菜单导入、3种PCM，之后原版和候选在同一QEMU均触发相同未建模寄存器访问，作为既有模型故障记录并暂缓，不视作长连拍通过。

原生超过64次播放、93张补充回归、普通快档完整回归、尾段期间快速重按、完整双卡拔插及长期实机稳定性未完成资格验证。组件的1001次选择、3000组循环和1000次回调压力不可替代实机次数。本版本为有明确边界的离线候选；完整内容见[验证说明](docs/validation.md)。

## 构建

依赖与命令见[English README](README.md)。自行提供SHA256匹配的原版MAIN模块，完整封包另需原版容器和私有格式材料。工具不下载这些输入。所有输出须保存在仓库外的私有目录。编译及整包输出必须与冻结v12哈希一致，并通过独立回读。

本项目仅覆盖mark2；QEMU修复、mark1和mark3为独立工作。历史v11保留于Git历史。仓库无相机控制、刷写或自动安装命令。
