# Z9 mark2 自定义快门声补丁

这是针对 **Z9 5.32** 的实验性源码项目，基线为 **mark2 v11**。仓库只提供自行编写的补丁源码、离线构建和校验工具，不提供尼康固件、尼康源码、原厂资源、私有格式材料、实机读回或可安装 BIN。

## 当前功能

- 菜单选择存储卡根目录 `CUSTOM_SOUND` 内的 WAV；目录不存在时创建，仅扫描本层文件。
- 最多显示 20 个自定义文件，只显示文件名；当前支持不超过 111 字符的可打印 ASCII 文件名。
- 支持 RIFF PCM、48 kHz、双声道、16 位、小端，长度 **大于 0 且不超过 1.5 秒**。其他格式不导入。
- 选择成功后外层菜单显示 `CUS`；保留原版 Type A–E 和音量控制。导入失败继续保留上一份已加载声音。
- 在同目录保存双记录配置，包含 CRC、序号和写后回读检查；首次拍摄音频请求时尝试恢复。

短音频加载失败的 v11 修复针对文件名消费者：优先读取目录项的完整 UTF-16 文件名，再转换为受支持的 ASCII 路径，避免将 8.3 别名误当作完整文件名。并非要求音频恰好 1.5 秒。

## 必须了解的限制

每次开机仅允许 **4 次导入尝试**，失败和自动恢复也计数；声音回调槽最多 **64 个且不重复使用**。第 65 次请求在适配层被拒绝，没有已证明的声音回退。当前版本不适合按无限次拍摄能力验收。

加载后的 PCM 缓存在内存中。拔卡不会立即清除它；重启后缺卡恢复失败不会自动重试，可重新手动选择。缺卡时切回 Type A 无法更新卡内旧配置，下次启动可能恢复旧的自定义声音。菜单尚无具体导入失败原因提示。

历史模拟验证中 C30/C60/C120 有限场景通过；C15 的拍后恢复检查仍未通过，声音传输本身通过。逐张声音同步已暂缓。v11 尚未得到实机、物理断电/热拔卡、声学音量及长期使用验证。用户此前确认安装启动正常的是较早的 v08，不应等同为 v11 实机通过。

## 使用与构建

命令和依赖见 [English README](README.md)。模块构建需要自行提供 SHA256 匹配的原版 MAIN 模块；完整封包还需要另行提供原版容器和私有格式材料。仓库不携带这些材料，也不会自动下载。新生成的固件、反汇编和日志必须放在仓库外的私有目录。

本轮独立提取后重建的 payload、模块及整包与冻结 v11 字节一致，并通过独立回读。仓库中的测试仅使用合成数据与原生接口模拟，不能代替相机验证。详细证据范围见 [验证说明](docs/validation.md)。

本项目仅覆盖 mark2 自定义快门声；原版固件上的 QEMU 功能修复、mark1 防抖开关以及 mark3 RAW 预拍摄属于独立工作。参考了 [Z8 补丁项目](https://github.com/XinmiaoZhao/NikonFirmwarePatch) 的源码配方及输入/输出身份检查方式，没有直接移植其补丁实现。
